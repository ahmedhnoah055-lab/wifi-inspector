# WiFi Inspector — كاشف الشبكة

تطبيق ويب تقدمي (PWA) باللغة العربية لإدارة بيانات الراوتر والأجهزة المعروفة وسجل نتائج الفحص.

## مهم قبل الاستخدام
- هذه النسخة تحفظ البيانات محلياً باستخدام IndexedDB وتعمل دون إنترنت بعد فتحها مرة أولى وتحميل ملفاتها.
- المتصفح لا يستطيع إجراء مسح شامل للأجهزة الموجودة على شبكة Wi-Fi أو قراءة بياناتها الخاصة. لذلك لا يظهر زر فحص وهمي؛ سجّل نتائج الفحص التي تحصل عليها من صفحة إدارة الراوتر.
- لا يمكن الوصول إلى الراوتر من خارج شبكة المنزل إلا إذا وفر الراوتر وسيلة إدارة عن بُعد آمنة ومفعّلة من مالكه.
- المزامنة السحابية غير مفعّلة في هذه الحزمة. ملف `firebase-config.js` يحتوي خانات إعداد فقط. يلزم إعداد Firebase Authentication وقواعد Realtime Database آمنة ثم تنفيذ طبقة المزامنة قبل تخزين بيانات حقيقية.

## النشر على GitHub Pages من الجوال
1. افتح مستودع `wifi-inspector` في GitHub.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، وليس ملف ZIP فقط.
3. من Settings ثم Pages اختر Deploy from a branch.
4. اختر `main` والمجلد `/ (root)` ثم Save.
5. انتظر النشر وافتح رابط GitHub Pages.
6. افتح الرابط مرة واحدة مع الإنترنت؛ بعد ذلك يمكن تثبيته كتطبيق ويب من قائمة Chrome عبر Add to Home screen.

## الملفات
- `index.html`: واجهة التطبيق.
- `style.css`: التصميم.
- `app.js`: التخزين المحلي وإدارة الأجهزة والسجل والتقارير.
- `firebase-config.js`: خانات إعداد Firebase.
- `manifest.json` و`service-worker.js`: التثبيت والعمل دون اتصال.
- `icons/`: أيقونات التطبيق.
